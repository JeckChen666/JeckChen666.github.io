GithubImagePush：把 GitHub 仓库变成你的免费图床

2026-10-11 · 开源项目 #开源项目 #图床 #GitHub #Go

写博客的人，都绕不开「图片放哪」这个的问题

在 Markdown 里写技术文章，截图、配图、示意图片是刚需。放在本地？换台电脑链接全断。放在免费图床？担心哪天跑路。买个对象存储？又要付钱、要备案、要配 CDN。

其实我们每个人手里都握着一个免费、稳定、全球可达的存储——GitHub 仓库。GithubImagePush 要做的事很简单：给 GitHub 仓库套一层友好的 Web 服务，让你像用专业图床一样，把图片丢进 GitHub，拿回直链。

为什么值得一试

1. 单二进制，裸服也能跑

Go 标准库 HTTP + embed 内嵌前端，编译出来就是一个文件，没有任何运行时依赖。scp 到服务器、注册一个 systemd 服务，部署就结束了。一台最低配的云主机（1 核 1G）绰绰有余——本站服务器上的实例常驻内存只有个位数 MB。

2. 上传体验对齐商业图床

  • 三种输入：multipart 表单、JSON base64（自动识别 data:image/png;base64, 前缀）、网页拖拽/粘贴
  • 一次上传，多种直链：raw 直链、jsDelivr CDN、GitHub 页面链接、自定义域名（支持 {path} 占位符），全部同时返回
  • 命名与冲突可控：默认时间戳命名防同名，也可保留原名；同名可选报错或覆盖

3. 鉴权认真做过的

多 Key 管理（方便分发与吊销）、常量时间比较防时序攻击、按 IP 限速防暴力枚举。v1.1.0 起还有了独立登录页，未登录访问自动跳转，Key 不再常驻页面角落。

4. 兼容 PicGo 生态

POST /upload 输出 PicGo 标准的 {success, result: [...]} 格式，Typora、PicGo 等工具的自定义 Web Uploader 直接可用，老工具无缝迁移。

5. 给 AI Agent 留了门

内置 GET /api/skill 接口和网页版「Skill 接入」指南：鉴权后返回一份含服务地址、Key 与完整安装步骤的 Markdown。把它丢给你的 AI Agent，它自己就能完成配置——从此「帮我把这张图传到图床」变成一句话的事。

快速开始

浏览器打开，右上角（v1.1.0 起在登录页）填入 Key，拖一张图进去——直链到手。

我的用法

本站的写作工作流是自托管的 JcWorkSpace：编辑器里粘贴或拖入图片时，它自动把图传到 GithubImagePush 并插入直链——写文章的手感与大型写作平台无异，图片却稳稳落在自己的 GitHub 仓库里。这篇文章的发布，同样只用了它网页上的两个按钮：Git 推送、构建发布。
